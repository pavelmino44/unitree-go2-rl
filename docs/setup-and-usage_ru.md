# Настройка и использование

В данном документе приведены инструкции по настройке окружения и основные команды, необходимые для запуска стека обучения с подкреплением для Unitree Go2.

## Окружение Python

В проекте используется виртуальное окружение Python для инструментов, связанных с Unitree и MuJoCo.

Виртуальное окружение расположено по адресу:

```text
~/unitree_env
```

Для его активации выполните:

```bash
source ~/unitree_env/bin/activate
```

## IsaacLab и Unitree RL Lab

Среда для обучения с подкреплением управляется с помощью Conda.

Активируйте окружение:

```bash
conda activate env_isaaclab
```

Это окружение используется для обучения и оценки RL-политики в IsaacLab, а также для запуска соответствующих инструментов развёртывания.

---

## MuJoCo

### Запуск симуляции MuJoCo

Активируйте окружение Python и запустите симуляцию MuJoCo:

```bash
source ~/unitree_env/bin/activate

cd ~/unitree-go2-rl/unitree_mujoco/simulate_python/

python3 ./unitree_mujoco.py
```

### Запуск ROS 2-узла `StandGo2Example`

Данный пример демонстрирует управление симулируемым роботом Go2 с использованием ROS 2.

```bash
source ~/unitree_env/bin/activate

source ~/unitree-go2-rl/unitree_mujoco/example/ros2/install/setup.bash

cd ~/unitree-go2-rl/unitree_mujoco/example/ros2

./install/stand_go2/bin/stand_go2
```

## Реальный робот

> **⚠️ Предупреждение:** Перед запуском программ низкоуровневого управления на реальном роботе необходимо отключить контроллер движения Unitree Motion Controller. Убедитесь, что робот находится в безопасном положении и не может упасть или неожиданно начать движение.

### Отключение Motion Controller

Для этого используется пользовательская утилита `go2_motion_switcher`, предоставляемая модифицированным репозиторием `unitree_sdk2`.

```bash
cd ~/unitree-go2-rl/unitree_sdk2/build/bin

./go2_motion_switcher eno1
```

С помощью этой утилиты необходимо освободить управление от Motion Controller перед запуском приложений низкоуровневого управления.

### Запуск `StandGo2Example` с ROS 2

> **⚠️ Предупреждение:** Перед запуском данного примера Motion Controller должен быть отключён.

Инициализируйте окружение ROS 2:

```bash
source ~/unitree-go2-rl/unitree_ros2/setup.sh
```

Затем запустите пример:

```bash
cd ~/unitree-go2-rl/unitree_ros2/example/

./install/unitree_ros2_example/bin/go2_stand_example
```

### Запуск обученной политики на реальном роботе

> **⚠️ Предупреждение:** Перед запуском RL-контроллера Motion Controller должен быть отключён.

Активируйте окружение IsaacLab:

```bash
conda activate env_isaaclab
```

Затем запустите контроллер Go2:

```bash
cd ~/unitree-go2-rl/unitree_rl_lab/deploy/robots/go2/build

./go2_ctrl --network eno1
```

Аргумент `--network` задаёт сетевой интерфейс, используемый для связи с роботом.

## Unitree RL Lab

### Запуск обучения с нуля

Для запуска нового эксперимента по управлению скоростью Go2 выполните:

```bash
./unitree_rl_lab.sh -t \
    --task Unitree-Go2-Velocity \
    --num_envs 6500 \
    --max_iterations 30000 \
    --headless
```

### Продолжение обучения из сохранённого состояния

Для продолжения ранее начатого эксперимента выполните:

```bash
./unitree_rl_lab.sh -t \
    --task Unitree-Go2-Velocity \
    --resume \
    --load_run 2026-05-15_00-29-16 \
    --num_envs 6500 \
    --max_iterations 20800 \
    --headless
```

Аргумент `--load_run` указывает директорию эксперимента, из которой необходимо продолжить обучение.

### Запуск и оценка обученной политики

Для запуска обученной политики в IsaacLab выполните:

```bash
./unitree_rl_lab.sh -p \
    --task Unitree-Go2-Velocity \
    --num_envs 30
```

Данный режим также может использоваться для экспорта обученной политики в формат ONNX для последующего развёртывания на роботе.

### Запуск контроллера в MuJoCo

Обученный контроллер можно протестировать в симуляции MuJoCo.

Активируйте окружение IsaacLab:

```bash
conda activate env_isaaclab
```

Затем запустите контроллер:

```bash
cd ~/Unitree_Isaac/unitree_rl_lab/deploy/robots/go2/build

./go2_ctrl
```

Контроллер взаимодействует с симуляцией MuJoCo через настроенный сетевой интерфейс и DDS.

## Сетевые интерфейсы

В текущей конфигурации используются разные сетевые интерфейсы в зависимости от целевой среды:

| Цель                         | Интерфейс                 |
| ---------------------------- | ------------------------- |
| Реальный Unitree Go2         | `Your_wired_interface`    |
| MuJoCo / локальная симуляция | `Your_wireless_interface` |

Эти значения соответствуют конфигурации текущей рабочей машины и могут потребовать изменения при воспроизведении проекта на другом компьютере.

## Примечания

* Конкретные версии программного обеспечения и commit'ы submodule определяются родительским репозиторием `unitree-go2-rl`.

* Параметры обучения настраиваются в `unitree_rl_lab`.

* Обученную политику можно оценивать как в IsaacLab, так и в MuJoCo.

* Для развёртывания на реальном роботе необходимо соответствующим образом настроить окружения Unitree SDK и ROS 2.

* Перед развёртыванием низкоуровневого контроллера на физическом роботе всегда тестируйте его в симуляции.
